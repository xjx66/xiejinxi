# 3D 空间深度分布说明

本文档用于说明当前 3D 场景中，沿 Z 轴（深度方向）各个层级和元素的具体分布情况。

在 Three.js 中，Z 轴的正方向是指向屏幕外（也就是向着玩家/相机的方向），Z 轴的负方向是指向屏幕内（也就是深处的背景方向）。

## 核心层级分布 (由近及远)

### 1. 相机初始位置 (Z = +40)
- **元素**: `bgCamera`
- **说明**: 页面刚加载时，背景相机的默认位置。此时视角最广，能看到最前排的角色。
- **变量**: `BG_Z_MAX = 40`

### 2. 角色交互层 (Z ≈ 0)
- **元素**: Avatar (虚拟数字人)
- **说明**: 第一排虚拟角色所在的层级。由于 `talkinghead.mjs` 中的角色渲染逻辑是独立叠加在 UI 层的，背景相机的 Z 轴移动（从 40 向 0 推进）会配合 CSS Transform 让角色放大并淡出（模拟“穿过”角色的效果）。

### 3. 产品展示层 (Z = -150)
- **元素**: `showcaseGroup` (包含实体模型 GLB 和虚拟全息视频 MP4)
- **说明**: 悬浮产品阵列所在的层级。当相机的 Z 坐标推进到 `[-80, -200]` 区间时，系统会判定用户进入了“产品层”，此时：
  - 产品对应的 3D UI 标签开始显示。
  - 视野中心的产品视频（如果有）会自动播放，并支持空格/方向键控制。

### 4. 画廊悬浮层 (Z = -294.6)
- **元素**: `paintingsGroup` (用户配置的照片、画作)
- **说明**: 曾经贴在墙上的画作阵列。由于墙面被再次向后推移，画作现在处于 Z = -294.6 的位置，**完全悬浮在半空中**。当相机推过产品层，进入 `< -160` 的区间时，产品标签隐藏，画作的标签开始显示。

### 5. 极致深空墙面层 (Z = -895)
- **元素**: `wall` (基础墙面), `wallPanels` (带有混凝土缝隙纹理的墙板阵列)
- **说明**: 场景的最深处背景。墙面被推到了极其遥远的位置，使得整个空间具有极强的纵深感和奇幻感。
- **关联限制**: 相机滚轮推进的绝对极限 `BG_Z_MIN` 被设定为 `-870`，保留了 25 个单位的余量，防止相机穿模进入墙体内部。

### 6. 环境雾气边缘 (Z = -1200)
- **元素**: `bgScene.fog.far`
- **说明**: 线性黑雾的完全吞噬点。雾气从距离相机 80 个单位开始产生，在 1200 个单位处达到最浓（全黑）。这个极远的设定确保了即使墙面在 -895，也能隐约可见，而不是被纯黑的雾气完全遮蔽。

## 纵向高度分布 (Y 轴补充说明)

为了让你更好地理解空间立体感，以下是 Y 轴的高度分布：
- **天花板灯阵列**: `Y = 40`
- **墙面及产品/画作中心**: `Y = 17.5` (即 `wallCenterY`，精确夹在地板和天花板的正中间)
- **相机初始高度**: `Y = 8` (随着滚轮推进，会像坐电梯一样平滑抬升到 17.5 进行平视)
- **地板瓷砖阵列**: `Y = -5`

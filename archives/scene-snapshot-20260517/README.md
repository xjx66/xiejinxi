# Scene Snapshot 20260517

This archive captures the visible scene content before switching the app to an empty system scene.

Included files:
- `system-assets.js`: system products, paintings, textures, avatar asset references.
- `default-world.js`: generated default world objects.
- `object-templates.js`: object templates and capabilities.
- `avatar-assets.js`: avatar runtime configurations.
- `talkinghead.js`: scene construction code including floor, ceiling, wall, tree, painting, product, and avatar runtime setup.

Purpose:
- Preserve all current built-in scene assets and environment construction code.
- Allow the live app to be cleared so future content can be imported manually via upload.
